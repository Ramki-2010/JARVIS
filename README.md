# JARVIS

An open-source, local-first personal AI operating layer.

JARVIS coordinates:
Research → Planning → Engineering → Testing → Verification → Reporting

Built around:
- Model independence
- Human control
- Capability-based permissions
- Sandboxed execution
- Independent verification
- Persistent task state
- Auditable autonomy
