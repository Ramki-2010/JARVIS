## 1. The contradiction

Section 25 (as amended by MCA-002) lets the Beta ship push-to-talk voice, but describes voice only as an input that becomes a validated intent. It says nothing about open conversation. ADR-0013 (accepted) lets a local model only summarise, explain, rewrite or draft, and calls the model demo optional. RK has decided that natural, open-ended conversation is mandatory for the Beta. An ADR cannot widen the Master Context (ADR-0001 D3), so one sentence is added here.

## 2. The sentence

Add to the end of the "v0.1 Beta sub-context (MCA-002)" block in section 25:

```text
In the v0.1 Beta, conversation by text and by voice is natural and
open-ended (greetings, follow-up questions, answers on any topic the user
raises), with replies generated by an approved local model that holds no
authority, and any action it suggests still passes the same intent, command
and policy path.
```

## 3. Not changed

Sections 26 (security), 27 (model strategy), 31 (first acceptance test), 32, 37, 39 and everything else. The Beta still does not meet section 31. No policy, code, ruleset or capability change. The exclusions stay: wake word, always-listening, barge-in, interruption, mobile, phone calling, external communication, cloud speech, LAN access, autonomous execution, unrestricted computer control, any model holding authority.

## 4. If rejected

The Master Context stands at `0.1-r2`. Conversation is limited to what ADR-0013 allows today (summarise, explain, rewrite, draft). The rest of the Beta is unaffected.
